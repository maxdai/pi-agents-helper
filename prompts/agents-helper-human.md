# 讨论插话（agents-helper-human）

**插话内容：$1**

这是用户要插入当前多 agent 讨论的 human 消息。执行步骤：

1. **确定当前讨论目录**：本会话中最近一次启动的讨论目录（`discuss.sh --start`
   输出的"目录:"路径）。若当前没有正在进行的讨论（已清理/未启动）→ 告知用户
   "没有正在进行的讨论"，不执行。
2. **执行插话**：

```bash
/root/pi-agents-helper/scripts/discuss.sh --say <讨论目录> "$1"
```

3. **反馈**：向用户反馈 `已发送 human/NNNN.md`，并简短说明 agents 下轮即可看到
   并可回应（已冻结的 agent 不响应，正常）。

## 注意

- 一次触发 = 一次插话，**立即完成并返回**，不进入任何轮询/状态循环。
- **插话内容就是 $1 本身**——原样写入讨论，保持完整（多行也完整保留），
  不要改写、总结或回答它。
- 用户若想启动新讨论，会用 `agents-helper` 命令（本命令不启动讨论）。
